# Twemoji Country Flags

`TwemojiCountryFlags.woff2` is the flag-only subset from
[talkjs/country-flag-emoji-polyfill](https://github.com/talkjs/country-flag-emoji-polyfill)
(Twemoji, © Twitter, [CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/)).

Windows Chromium draws regional-indicator pairs as letter codes (BR, GB…).
This font is scoped with `unicode-range` to those codepoints so Events flags
render as actual flags without affecting body text.
